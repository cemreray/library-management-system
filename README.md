# Library Management System

A simple library management system developed with Python using Object-Oriented Programming principles.

## Features
- Add books
- Delete books
- Update books
- List books
- Add magazines
- Delete magazines
- Update magazines
- List magazines
- Duplicate record number prevention
- Encapsulation with property and setter methods
- Inheritance
- Abstract classes
- Menu-based system

## Technologies
- Python
- Object-Oriented Programming (OOP)

## Concepts Used
- Classes
- Inheritance
- Encapsulation
- Abstract Classes
- CRUD Operations
